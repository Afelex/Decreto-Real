# Retratos maestros · Decreto Real

Esta carpeta está reservada para las 13 imágenes PNG maestras del paquete `decreto_real_biblia_visual_12_personajes.zip`.

Para incorporar las referencias visuales sin cambiar las imágenes activas del juego, abrir esta carpeta en GitHub y seleccionar **Add file → Upload files**. Arrastrar aquí los archivos PNG que están dentro de `art-reference/personajes-oficiales/imagenes/` del paquete; confirmar el commit. No subir el ZIP entero como sustituto de los PNG.

Los nombres esperados, los personajes y los SHA-256 de los originales figuran en `../catalogo.json`. La documentación no significa que las imágenes estén publicadas: comprobar los PNG individualmente en este directorio.
